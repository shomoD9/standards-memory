# Acme Notes: project scope, release 1

## Goal

Deliver the three features from the product brief to a closed beta of ten workspaces.

## In scope

- Markdown editor with live preview.
- Search index and query API, with a command-line tool for loading test data.
- Decisions tag and the per-workspace decisions page.
- Automated tests for the API and the indexer; CI must pass before any release.

## Out of scope

- Mobile apps.
- Export formats other than Markdown.
- Paid plans and billing.

## Milestones

| Week | Milestone |
| --- | --- |
| 1-2 | Editor and storage |
| 3-4 | Search index and API |
| 5 | Decisions page |
| 6 | Closed beta |

## Open questions

Which hosting region should the beta use? The platform owner will decide by the end of week 1.
